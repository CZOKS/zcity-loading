ZCITY MADNESS — бесплатная статическая версия

Установка на GitHub Pages
1. Зарегистрируйся на https://github.com/ и открой https://github.com/new
2. Создай Public репозиторий zcity-loading, включив Add README.
3. Распакуй ZIP. В репозитории Add file → Upload files загрузите содержимое
   архива: index.html, style.css, app.js, playlist.js, папки assets и videos.
   index.html должен быть прямо в корне репозитория, не во вложенной папке.
   Нажми Commit changes. Загружать нужно распакованные файлы, не ZIP.
4. Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
5. Дождись публикации (может занять до 10 минут). В Pages нажми Visit site.
6. Проверь адрес без VPN. Доступность у конкретного провайдера не гарантируется.
7. В консоли игрового СЕРВЕРА выполни команду со своим фактическим адресом:
   sv_loadingurl "https://YOUR_LOGIN.github.io/zcity-loading/"
8. Такую же строку добавь в garrysmod/cfg/server.cfg для сохранения настройки.
   Переподключись к серверу для проверки загрузочного экрана.

Только твои видео
В videos лежат 10 твоих роликов WebM. Картинки и шрифт также локальные.
Переключение автоматическое после окончания ролика; кнопки перемотки и
следующего ролика отсутствуют. Есть регулировка громкости.
Браузер может запрещать автозапуск со звуком: тогда нажми кнопку включения звука.
Прогресс загрузки поступает от GMod; в обычном браузере он не имитируется.

Как добавить или удалить видео
Управление выполняется через ТВОЙ аккаунт GitHub. Отдельной веб-админки нет.
Не предоставляй другим аккаунтам права записи в репозиторий.
Посетители могут смотреть и скачивать опубликованные ролики, но не менять сайт.
Добавление: загрузи ролик в videos, затем отредактируй playlist.js в GitHub.
Добавь объект по образцу существующих, разделяя объекты запятыми:
  {"title":"Моё видео", "sources":["videos/my-video.webm"]}
Удаление: удали объект из playlist.js и при желании сам файл из videos.
Нажми Commit changes и дождись повторной публикации.
Используй WebM VP8/VP9 с Opus/Vorbis; произвольные MP4 могут не играть в GMod.
Пути относительные, без начального /. Регистр имён файлов важен.
При загрузке через браузер GitHub отдельный файл должен быть меньше 25 MiB.

Ограничения
GitHub Pages бесплатен для публичного репозитория. Мягкий лимит трафика:
100 ГБ в месяц; опубликованный сайт до 1 ГБ. Видео расходуют трафик.
Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
Эта версия не зависит от chatgpt.site и его серверной админки.
Проверка внутри твоей версии GMod и у твоего провайдера всё ещё нужна.
